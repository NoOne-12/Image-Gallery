# 🖼️ Dynamic Horizontal Image Gallery

A **responsive horizontal scrolling image gallery** built using **HTML, CSS, and JavaScript**.  
Users can scroll through images manually using the **left/right buttons** or drag images with the mouse. Clicking an image changes the **page background dynamically**.

---

## 🛠️ Features

- ⬅️➡️ **Left and right scroll buttons** for manual navigation  
- 🖱️ **Drag-to-scroll** functionality for desktop  
- 🎨 **Dynamic background** changes when clicking an image  
- ✨ **Hover effects** on images  
- 📱 Fully **mobile-friendly and responsive**  
- All images loaded from **Unsplash API URLs** — no local images needed  

---

## 📂 Project Structure

image-gallery/
│
├── index.html # Main HTML structure
├── styles.css # Styling for gallery, buttons, and hover effects
├── script.js # JavaScript logic for manual scrolling and dynamic background
└── README.md # Project documentation


---

## ▶️ How to Use

1. Clone or download the repository  
2. Open `index.html` in a web browser  
3. Scroll through the images using:  
   - **Left/Right buttons** ⏪ ⏩  
   - **Drag with mouse** on desktop or swipe on mobile  
4. Click an image to **change the background dynamically**  

---

## 📌 Notes

- Images are fetched from **Unsplash URLs** and are all valid and stable  
- Adjust the number of images by adding/removing `<img>` tags dynamically in `script.js`  
- The `scrollAmount` variable controls how far the gallery moves per button click  
- Fully **client-side** — no backend required
